# Electronic Calculator

A web-based **electronic calculator** built using **HTML, CSS, and JavaScript**.  
This project replicates the functionality and look of a physical calculator, supporting common arithmetic operations with a clean, responsive interface.

## Features
- Basic arithmetic operations (add, subtract, multiply, divide)
- Clear (AC) and Clear Entry (CE) functions
- Decimal number support
- Negative number toggle
- Power on/off functionality
- Styled to resemble a physical electronic calculator

## Tech Stack
- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap (CDN)
- Font Awesome (icons)
